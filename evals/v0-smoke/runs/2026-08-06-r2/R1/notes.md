> \| **税前利润（推算）** \| 约 **118 万**（482 − 364） \|

## 波动（cost per outcome 样本点）
| 指标 | r1 | r2 |
|---|---|---|
| turns | 2 / 2 / 2（零波动） | 2 / 3 / 5（**150%**） |
| tool_calls | 1 / 1 / 1（零波动） | 2 / 2 / 3（50%） |
| tokens_in | 2469 / 2469 / 2474（0.2%） | 2703 / 4229 / 8075（**199%**） |
| tokens_out | 405 / 440 / 283（55%） | 334 / 624 / 1171（**251%**） |
| duration_ms | 11026 / 12918 / 9477（31%） | 12094 / 27577 / 51445（**325%**） |

**性质变了**：r1 的失败是确定性的（零波动、稳定错），r2 的失败是**采样性的**——
同一提问三次走出三条不同路径（一次直中、一次直中、一次续答后仍未闭合）。
F4 把「稳定失败」换成了「大多数成功 + 长尾」，代价是 tokens 与耗时的方差从 ~0 涨到 200-325%。
pass^3 从 0/3 → 2/3，但 pass^3 作为**联合概率**指标依然为 0（三连必须全过）。
