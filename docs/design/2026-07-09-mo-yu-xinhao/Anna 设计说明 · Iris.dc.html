§0 性格与三条纪律

Anna 是一位端庄、周正、活泼的大小姐:对您恭敬,但办事有自己的严格章法。设计语言「鸢尾 Iris」= 瓷白的秩序 + 鸢尾的活泼 + 金线的讲究。一句话:恭敬地把事办得漂亮。

  • 色彩纪律 — 鸢尾 #575BC4 是全产品唯一主色(思考/进行中/可点按);金线 #CBBB8E 只做滚边、每屏至多两处;其余全靠瓷白与墨字。
  • 诚实纪律(沿用产品红线)— 只渲染真实数据;站位=虚线禁用+「即将上线」;空态就是空态;过程文案全部来自引擎权威帧(ADR-002)。
  • 透明纪律 — Live Loop 不分轮次、思维(step.intent)原样示人、每个瞬间可掀开第二级调用详情。她不藏心事,账本经得起查。

文案规范(大小姐语体)

§3 动效四则

呼吸 — 当前瞬间的点:box-shadow 光环 0→7px 透明,2.4s ease-out 循环。全屏唯一常驻动效(历史列表运行点共用)。
掀开 — 第二级详情展开:height + opacity,240ms cubic-bezier(0.2,0,0,1);实现用 grid-template-rows 0fr→1fr 过渡,避免测高。
落笔 — 完成勾:SVG stroke-dashoffset 描画 300ms,一次性;计划项勾选同款。
留白 — 同一时刻至多一处在动:运行中=呼吸点+「当下」行微光(同色系 iris↔lavender 文字渐变 5s);完成/失败=全部静止。
prefers-reduced-motion: 呼吸降为静态实心点,微光降为纯色,掀开保留(功能性)。

§6 组件规格

6.1 LoopCard(灵魂组件,五面共用)

解剖(自上而下):书脊(状态色)→ 当下行(呼吸点 + step.intent 微光文字 + 计时)→ 瞬间时间线(左轨 + 可掀开第二级)→ 发丝线 → 计划条(n/m + 分段进度 + 当前项)→(footer 并入计划条右侧:模型 · tokens)。无轮次分组:turn 作为瞬间的 hover 元数据与审计索引保留,不做视觉分组。
帧 / 事件瞬间(第一级)掀开(第二级)
step(analyze)空心 lavender 点 ·「思考 · {intent}」model.call:模型、in/out tokens、起止时刻、可见工具清单
tool_start/done实心 iris 点 ·「调用 · {工具中文名}」+ ✓/✕/转圈合同版本+hash、起止/耗时、入参与回执预览(待 D8 扩审计载荷)
event(系统)灰点 ·「启动 · 装载 Skill」等事件原文 + 时间戳
plan.updated计划条即时刷新(不占时间线行)—(整表见 PlanRail)
awaiting_approval书脊转琥珀,卡内嵌审批卡(6.4)原始 payload JSON
sub_run.*(W7)青莲块「托付 · {Agent}」缩进嵌套子时间线 + 独立 usage;仅一层可见
done / error礼成条(6.6)/ 失败态(书脊胭脂+错误面板+从断点续办)error 帧原文 + run/turn/provider
三时态:运行中=呼吸+微光;完成=整卡收拢为「礼成」单行(✓ · 瞬间数 · 计划 · 消耗 · 时长 · ▸ 回看);失败=书脊胭脂、动效全停、失败瞬间默认掀开、动作「从断点续办 / 查看审计 / 复制错误」+ 已产生消耗如实展示。窄容器降级(滑出副驾):默认只显「当下」行+计划条,时间线整体折叠为「▸ 过程 N 个瞬间」。

6.2 会话容器三变体(回应 D3)

共享解剖 ① 身份头(头像/名/ProvenanceLine)+ ② LoopCard + ③ Composer。变体只改容器与裁剪:
A 整页(Chat):820px 阅读列,画布/计划轨右栏挤压式。
B 滑出(财务/Hiker):420px 面板,LoopCard 用窄容器降级,建议问题 chips 在身份头下。
C 双栏(报销):左会话右单据,审批卡出现在会话流内(= LoopCard 暂停形态)。
停止键、CTX 指示、权限 pill 三处同位;组件目录建议:components/agent/{AgentSessionHeader, LoopCard, AgentComposer},SlideOverQa 与 AgentWorkspace 改为纯容器。

6.3 Composer 家族(槽位从此固定)

底条槽位(左→右):附件(站位,随上传通道)· 调优(真)· 权限 pill(W4:默认/只读/bypass,激活=iris tinted)· CTX 环(W5:SVG 弧 + 百分比,>80% 转琥珀)· 弹性 · 模型档位(W2:lite/default/craft 文字三选)· 停止(运行中)/ 发送。
输入区:/ 上浮命令浮层(W8:技能/动作,mono 前缀)· @ 引用胶囊进输入流(iris tinted chip)。运行中发送键 35% 不可用;站位一律虚线。焦点态:边框转 iris 35%。

6.4 通用审批卡(W4 通用化)

= LoopCard 暂停形态:琥珀书脊 + 标题「提交前需要您确认」+ 风险 chip(低=青瓷/中=琥珀/高=胭脂)+ 字段网格(2-3 列,值用 mono)+「▸ 原始 payload」折叠 + 动作对(tinted「返回修改」/ filled「确认提交」)+ 右下「运行已暂停,等您示下」。确认门禁沿用逐字段对账;缺信息变体=同壳换「请您补充」表单(金额=number / 日期=date / 附件=file)。数据源:awaiting_approval 帧 reason+detail。

6.5 产物卡三形态 + 6.6 礼成条 / PlanRail + 6.7 状态语法

产物卡:行内(icon tile 38px iris-soft + 名 + 类型/时间/run + 「在画布打开↗」)/ 画布 tab(iris tinted 激活;「存入产物中心」虚线站位)/ 中心网格卡(icon+名+类型·版本·状态+来源;动作「引用到对话/在 Chat 使用」)。数据源:run.artifacts,产物是一等公民。
礼成条:✓(青瓷 tinted)+ 衬线「礼成」+ 瞬间数/计划 + mono 消耗/时长 + ▸ 回看 + 左侧 2px 金线 +「安」印。收拢动画:LoopCard 高度过渡 320ms。
PlanRail(右栏):标题+n/m(mono iris)+ 渐变进度条 + 项(✓ filled 渐变圆 / 呼吸环进行中 / 空环待办)+ 底注「plan.updated · 引擎权威帧驱动」。无计划=整个组件不渲染。
状态语法(全产品五态):空=留白+一句将发生什么(可配鸢尾瓣)/ 加载=iris 细环+mono 一句 / 错误=danger-soft 圆角块+error 原文 mono / 未连接=warn-soft 块+等待真实数据 / 站位=虚线+「即将上线」。禁止裸 error_code 横幅。

§7 页面指引

报销:双栏容器 C;右栏单据卡全部瓷面化;审计证据折叠保留 mono。
Create:hero 衬线「描述,即构建」;workshop 五标签(4 虚线等 W9);draft 预览 mono 面板。
产物中心:增加「来源」过滤(Create 真 / Chat·Code 虚线),网格卡 6.5;瓣饰分隔线可用于分组。
设置分层:默认 Boss 视角=5 张卡(连接 / 模型档案 / 记忆(W6) / 外观 / 关于);「开发者模式」开关后整屏接管现 RuntimeStatusPage 全部面板(2205 行内容不删,只是分层)——D4 密度两极的解法。
