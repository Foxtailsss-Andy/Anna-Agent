一 · 设计立场(第一性)

协同工具的原罪是「被推着走」:红点轰炸、任务像债。Crew 的反命题——工作是一株看得见生长的活物,人是照料者不是欠债人。落成四条可验的机制:

  • 动静即事实:界面上任何动效都对应一个真事件(状态机 transition + audit),无事件则界面静止。安静=真的没事,于是安静可信,人才能安心离开屏幕。
  • 生长有仪式:图长新枝是 money-shot,四幕收在 1.1s 内——克制的仪式感让「组织在推进」成为愉悦而非噪音。
  • 通知会归位:弹卡驻留 6s 后「收进铃里」,徽标 +1。通知不消失、不催促,只是归位等你——铃替你记着,你不必替系统记着。
  • 零就是零:空态短句、计数为零则隐藏 chip、无执行则无呼吸。不装忙,是对注意力的礼貌。

五 · 六命题裁决

P1 呼吸唯一性——呼吸跟随「当下」:最近一次真 transition 的执行中节点获得呼吸,全画布唯一;其余执行中节点=静态 iris 实心章+描边;无执行则无呼吸(1b 深色屏即此态:评审时刻,画布全静,唯一的动是等待人的金门)。焦点让渡在下一次 transition 时切换,不抢。理由:呼吸是 Anna 的心跳,不是繁忙指示器;多处呼吸=噪音,零呼吸=诚实。

P2 生长时刻——四幕:让位(elk 重算滑移)→ 画入(边落笔)→ 显形(节点掀开)→ 定名(金线一周,礼成)。1.1s 收场,强调晕 3s 淡尽;节点留 mono 溯源行「由频道生长 · #audit」作为永久的、安静的出生证明。仪式感给足一次,不重播。

P3 Anna 的口吻与版式——裁决:事件不是卡,是编年史的一行。频道立一条脊线,Anna 以鸢尾瓣为结、serif 署名记事:一行事实+@人+锚点+audit 编号,无容器不抢眼;产物/评审/命令才是「放上桌的东西」,以卡呈现。轻拟人=Anna 只陈述事实与下一步,永不用感叹号、永不催。

P4 人机同构身份——第一通道是形状:人=正圆,Agent=方圆角(40px 头像 r13 / 16px r5),圆与方在 12px 下仍可辨,不依赖色觉。第二通道 delegate 紫:Agent 头像底/名字色/AGENT mono 章。第三通道图元:Scribe=三横 · Design=圆叠方 · Check=对勾,1.5-2px 描边,永不用人脸。五处(头像/名牌/频道结/花名册/节点署名)同一套。Anna 自己=鸢尾瓣+serif,既非人也非 Agent 成员——她是主持。

P5 铃的秩序——铃=外壳右上唯一常驻入口(32px),与侧栏底自检 chip、UserChip 三角分立:铃管「别人找我」,自检管「系统健康」,UserChip 管「我是谁」。登录时刻弹卡≤3、6s 后收进铃(通知归位);会话中跨段通知=徽标+单次摆动,不弹卡不打断;同段事件优先落在频道/画布现场,铃只记账。

P6 三向锚点——统一「点名环」:平移居中 320ms → iris 环单脉冲 → 驻留 2.4s → 淡出。频道卡、图节点、抽屉、收件箱行共用同一语言;被指认的对象只被「点名」一次,绝不循环闪烁。与呼吸(常驻、属于执行)在语义与波形上都分开(单脉冲、属于指认)。

六 · 真数据边界与站位

P0 全真:图/频道/通知/收件箱/花名册/模板/健康条/报销投影,事件卡右缘一律带 audit 编号(mono 9px ink-3,可由 Tweaks 关闭显示)。站位(虚线+「P1 即将上线」+disabled):看板视图 · 就地审批 · 模板编辑器 · 负载视图 · pin 节点。不画的东西:在场绿点 / 已读回执 / 子线程 / 表情回应——P0 不存在,稿中亦无。健康条计数为零的 chip 直接隐藏。

七 · 第三轮立场 · 动效双层制(红线修订)

立场延续:Crew 已「能用」,本轮把它变得「好用且有存在感」。四条主动脉——读产物 / 看运行 / @协作 / 画布存在感。不是重设计:外壳 · 三区 · 卡片族血缘全部沿用第二轮,未提及的屏一律以 v2 为准。

  • 红线第 5 条修订 · 动效双层制:动效分两层。注意力层=呼吸 anna-breath,全屏唯一常驻,只属当下焦点;状态层=「执行中」流光(R2),允许多节点同时存在,但视觉强度必须低于焦点呼吸,reduced-motion 下降级为静态标识。除这两层外不新增常驻动效。
  • 红线新增第 7 条 · 动效不撒谎:任何「正在运行」的视觉必须绑定后端真实 running 状态,状态一变动效即撤;不设计装饰性忙碌。故 R2 选「描边流光」而非「进度环」——后端只给「在飞」信号(run 状态 + 起跑时刻),并无确定进度%,进度环会撒谎。
  • 无新增主色:R1–R6 全部由既有 token 派生(iris 唯一主色、金线每屏至多两处、--delegate 属 Agent 不变);本轮新增的是结构与动效规格,不是颜色。

八 · 第三轮组件规格增补(可直接工程化)

附件 chip 家族(R1 · 稿 3g):产物 chip=文档图标 + 名 + 版本 + 字数 + 三动作(展开 / 全幅阅读 / 下载,全幅=iris 主动作,余中性);链接卡变体=站点图标 + 标题 + 域名 + 外链;say 内联引用 chip。产物卡 / 评审卡 / Agent 交付事件卡统一嵌用同一 chip 语法;窄频道(328)动作收敛为「全幅阅读 + …」溢出菜单。字数/版本/时刻均来自真实元数据,无产物则无 chip。

执行流光 + 活动行(R2 · 稿 3d):执行中节点边框 1.5px iris→lavender 慢流(strokeFlow 4.5s linear ∞,遮罩渐变边),强度 < 呼吸,可多节点同屏。频道「正在执行」活动行=脉点(runPulse 2s)+「正在执行『任务』· 已运行 mm:ss」(elapsed 真值),完成后消隐、由产物卡接棒。健康条「活跃 Agent n」在有 running 时点亮——图 / 频道 / 健康条三处同订阅「在飞」信号,同源同拍。reduced-motion=静态 iris 描边 + 徽记。

节点状态语汇升级(R5 · 稿 3a–3c):由「状态靠读字」升级为三层「状态即形色」——左缘 5px 状态色条(远读层,r 14/0/0/14)+ 卡面轻染(氛围层)+ 20px 章(近读层,色盲靠形状)。七态色条取色:待就绪 ink 12%(退后)/ 就绪 iris / 执行中 iris + 流光 / 已提交待审 lavender / 阻塞 danger + 洗色(最刺眼)/ 返工 danger 细边无洗色 / 完成 ok + 沉入面板色。门三态更重:待就绪(虚线退后)/ 活跃(44→48 + 金线 + 金脉,关卡仪式)/ 已通过(ok 勾 + 落章)。边四型对比拉大:已通电(实 ink 32%)/ 休眠(dash 5-4 淡)/ 焦点流动(iris dash 5-7 dashFlow)/ 返工回路(danger dash 3-3 上弧,通过后消隐不留疤)。三米可读:投影会议室大屏也能一眼看出谁在跑 / 谁卡住 / 谁在等。

九 · R1–R6 裁决与理由

R1 产物是一等公民——三档阅读逐级放大(chip → 内嵌展开 → 全幅阅读器),不强跳。对照评审=左读右裁,故阅读器占画布、频道留右。解「产物太小、PRD 没法读」的病根:产物从「频道里一行小字」升为可展开/可全幅/可下载。

R2 执行看得见,但不撒谎——选描边流光不选进度环:后端只有「在飞」信号无确定进度,进度环会谎报百分比(红线 7)。强度阶梯 呼吸 > 流光 > 脉点,保证焦点恒唯一。短跑任务由「在飞」信号直通快照,两拍之间跑完也可见。

R3 产出先行——Boss 要的是结果不是过程。抽屉信息序把产物提到第一(默认展开),过程默认折叠、即点即关;原文渲染不再裸奔,长文内滚不贪占滚动区。

R4 频道即指挥部——@拾取器补齐「输 @ 拉人」;Anna 监察把自由发言里的派活意图拟成草稿卡,人落章才进图(ADR-002:模型起草,人决策)。口吻轻——她在建议不在代办;误听点忽略即无痕。这是本轮的灵魂。

R5 状态即形色——三层(色条/轻染/章)同源、任一层独立成立。阻塞必刺眼(danger 洗色)、执行显活性(iris 流光)、完成沉稳(沉入面板)、待就绪退后;门更重、金线只给门与生长第四幕。约束不破:暖底不换、iris 唯一、金线每屏至多两处、不做彩虹满屏。

R6 Enter 发送——顺手(Boss 习惯),Shift+Enter 换行;IME 守卫防组词误发;表单多行框不改防误提交长文。微提示常驻而非仅聚焦现身——迁移期需要持续提醒。
