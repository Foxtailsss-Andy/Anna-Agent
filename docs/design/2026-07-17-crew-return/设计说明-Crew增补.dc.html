一 · 设计立场(第一性)

协同工具的原罪是「被推着走」:红点轰炸、任务像债。Crew 的反命题——工作是一株看得见生长的活物,人是照料者不是欠债人。落成四条可验的机制:

  • 动静即事实:界面上任何动效都对应一个真事件(状态机 transition + audit),无事件则界面静止。安静=真的没事,于是安静可信,人才能安心离开屏幕。
  • 生长有仪式:图长新枝是 money-shot,四幕收在 1.1s 内——克制的仪式感让「组织在推进」成为愉悦而非噪音。
  • 通知会归位:弹卡驻留 6s 后「收进铃里」,徽标 +1。通知不消失、不催促,只是归位等你——铃替你记着,你不必替系统记着。
  • 零就是零:空态短句、计数为零则隐藏 chip、无执行则无呼吸。不装忙,是对注意力的礼貌。

五 · 六命题裁决

P1 呼吸唯一性——呼吸跟随「当下」:最近一次真 transition 的执行中节点获得呼吸,全画布唯一;其余执行中节点=静态 iris 实心章+描边;无执行则无呼吸(1b 深色屏即此态:评审时刻,画布全静,唯一的动是等待人的金门)。焦点让渡在下一次 transition 时切换,不抢。理由:呼吸是 Anna 的心跳,不是繁忙指示器;多处呼吸=噪音,零呼吸=诚实。

P2 生长时刻——四幕:让位(elk 重算滑移)→ 画入(边落笔)→ 显形(节点掀开)→ 定名(金线一周,礼成)。1.1s 收场,强调晕 3s 淡尽;节点留 mono 溯源行「由频道生长 · #audit」作为永久的、安静的出生证明。仪式感给足一次,不重播。

P3 Anna 的口吻与版式——裁决:事件不是卡,是编年史的一行。频道立一条脊线,Anna 以鸢尾瓣为结、serif 署名记事:一行事实+@人+锚点+audit 编号,无容器不抢眼;产物/评审/命令才是「放上桌的东西」,以卡呈现。轻拟人=Anna 只陈述事实与下一步,永不用感叹号、永不催。

P4 人机同构身份——第一通道是形状:人=正圆,Agent=方圆角(40px 头像 r13 / 16px r5),圆与方在 12px 下仍可辨,不依赖色觉。第二通道 delegate 紫:Agent 头像底/名字色/AGENT mono 章。第三通道图元:Scribe=三横 · Design=圆叠方 · Check=对勾,1.5-2px 描边,永不用人脸。五处(头像/名牌/频道结/花名册/节点署名)同一套。Anna 自己=鸢尾瓣+serif,既非人也非 Agent 成员——她是主持。

P5 铃的秩序——铃=外壳右上唯一常驻入口(32px),与侧栏底自检 chip、UserChip 三角分立:铃管「别人找我」,自检管「系统健康」,UserChip 管「我是谁」。登录时刻弹卡≤3、6s 后收进铃(通知归位);会话中跨段通知=徽标+单次摆动,不弹卡不打断;同段事件优先落在频道/画布现场,铃只记账。

P6 三向锚点——统一「点名环」:平移居中 320ms → iris 环单脉冲 → 驻留 2.4s → 淡出。频道卡、图节点、抽屉、收件箱行共用同一语言;被指认的对象只被「点名」一次,绝不循环闪烁。与呼吸(常驻、属于执行)在语义与波形上都分开(单脉冲、属于指认)。
