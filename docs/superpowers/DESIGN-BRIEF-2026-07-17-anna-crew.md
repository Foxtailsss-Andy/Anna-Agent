## 0. 一句话委托

> 为 Anna 设计 **Crew——组织协同区**:一张**人机同构的活 Work Graph**(横向动态 DAG 画布)+ 一条 **Anna 主持的项目频道** + 一个**组织收件箱与外壳级通知铃**。Anna 既是调度员(拆解/派人/催办/评审),也是图上的第一批员工(Agent 真干活)。请交付像素级设计稿与设计说明增补,我们将 1:1 落地。

三段 IA 的分工:**Home = 我让 Anna 干活;Cowork = 业务系统值守;Crew = 组织协同。**

### 不可违背的红线(与 Iris 轮相同,新增两条)

1. **零捏造**:每个状态、每张事件卡、每个数字都对应后端真事件(状态机 transition + audit);不设计任何"假装繁忙"的装饰性状态。空态即空态。
2. **persona 不骗人**:Agent 成员必须一眼可辨(不伪装成人类);拟人皮不遮盖真实运行状态。
3. **emoji 全禁**(2026-07-15 拍板,产品 UI 内一律不用 emoji;语义用图标/颜色/文字表达)。
4. **双主题必须**:浅色 + 深色(深色**非反相**,见 §2);新增 token 必须给双值。
5. **iris 是唯一主色**;金线滚边每屏至多两处;不引入新主色(Agent 身份色已有预留,见 §2)。
6. **可落地**:画布将用 React Flow + elkjs 实现(节点 = HTML/CSS 卡片,边 = 可定制 SVG)。请给**组件规格**(尺寸/间距/字号/token/动效时长),不要给无法工程化的整版手绘效果。

## 1. 产品定位速览(30 秒)

- **三面一体**:Graph(结构:工作是一张会生长的图)× Channel(沟通:进度由 runtime 事件自动长在频道里,Anna 主持、@人即组织)× Memory(认知:项目共识,人与 Agent 同读)。
- **五个签名特性**:一张活的图 / Anna 主持的频道 / 人机同构(Agent 是花名册正式成员)/ 组织收件箱(项目的事 + 业务系统的事汇到同一个铃)/ 团队共享 Memory。
- **对标差异**:Asana 2026-06 发布 Agentic Work Management(human-agent teams 的 OS),但它的 Agent 是接出去的;Anna 的 Agent 跑在体内,与人共享同一状态机、同一评审门、同一审计。
- **图会生长**(本轮灵魂):评审驳回长出返工回路;频道里一句话经 Anna 起草、Boss 确认后长出新分支;阻塞让节点变红。布局自动重算 + 动画过渡。

- **生长时刻**:新节点入场动画 + 短暂高亮(命题 P2);布局重排的过渡(节点滑移)。

## 4. 六个设计命题(交给你发挥)

- **P1 节点状态语汇与呼吸唯一性**:Iris 规定"呼吸是全屏唯一常驻动效"。画布上可能**同时有多个 Agent 在执行**——建议方向:仅"当下焦点"节点呼吸,其余执行中节点用静态 iris 点亮/微光;也欢迎你给出更好的解法,但**不得**让满屏节点一起呼吸。
- **P2 生长时刻**:新分支入场是本产品的 money-shot。请在 Iris 动效语言(掀开/落笔/微光)内设计:新节点如何出现、边如何画入、重排如何过渡、强调多久收场。克制而有仪式感。
- **P3 Anna 主持的口吻与事件卡版式**:频道里 Anna 的事件卡要"轻拟人、不装忙"——一行事实 + @人 + 锚点,与 LoopCard/答复排版同血缘。请给出 Anna 署名的视觉(鸢尾瓣?)与人类/Agent 署名的差异。
- **P4 人机同构身份系统**:human 与 agent 在头像、名牌、频道署名、花名册、节点 assignee 五处如何一致地区分。`--delegate #9C56B8` 已预留;Agent 头像建议几何化(非人脸),但由你定。
- **P5 通知铃的外壳落位**:右上铃与现有自检 chip(侧栏底部)、UserChip 的秩序;弹卡堆叠的层级、间距、消隐节奏;跨段(在 Home/Cowork 时收到 Crew 通知)的呈现克制度。
- **P6 三向锚点的焦点语言**:频道卡 ↔ 图节点 ↔ 任务抽屉互相跳转时,"被指向的对象"如何短暂强调(画布平移+强调环?)且不打扰。

## 7. 布局与技术约束

- 设计基准 **1440×900**;最窄 1200(频道可折叠成条)。Electron 桌面壳,窗口可缩放。
- 画布实现 = React Flow + elkjs(从左到右自动布局):节点 = HTML/CSS 卡片(你的规格可直接实现);边 = SVG(色/虚线/箭头可定制);缩放范围建议 0.5–1.5。
- 实时性 P0 = 3-5s 轮询:状态变化是"跳变"而非流式——过渡动画要能吸收跳变(例如状态切换 240ms 掀开缓动)。
- 字体三栈随包(§2.1),禁 CDN;图标延续内联 SVG 1.5px 描边。
- `prefers-reduced-motion`:呼吸→静态点;生长动画→直接出现+静态强调;平移→瞬时。
