## 2. 红线(承袭上轮 6 条,其中第 5 条本轮修订,另新增 1 条)

1. **零捏造**:每个状态、动效、数字都对应后端真事件;空态即空态。
2. **persona 不骗人**:Agent 一眼可辨,拟人皮不遮真实运行状态。
3. **emoji 全禁**(语义用图标/颜色/文字)。
4. **双主题必须**(深色非反相;新 token 给双值)。
5. **动效双层制(本轮修订)**:动效分两层——**注意力层**:呼吸 `anna-breath` 仍是全屏唯一常驻,只属于当下焦点;**状态层**:「执行中」指示动效(R2)允许多节点同时存在,但视觉强度必须低于焦点呼吸,reduced-motion 下降级为静态标识。除这两层外不新增常驻动效。
6. **iris 唯一主色**;金线每屏至多两处(评审门是金线的天然用户);Agent 身份色固定 `--delegate #9C56B8`。
7. **动效不撒谎(新增)**:任何「正在运行」的视觉必须绑定后端真实 running 状态,状态一变动效即撤;不设计装饰性忙碌。

## 4. 六个命题详述

### R1 产物的「读」:三档阅读 + 附件化(P0 ★)

产物(PRD/设计说明/代码说明…)是 Crew 的第一等公民,现在被锁在小盒子里:频道栏定宽 **328px**,产物消息卡只有标题+一行摘要(正文根本不在频道),唯一就地可读处是评审卡内 **~300×320px** 的滚动盒,任务抽屉里的产物预览也只有 **260px** 高。请设计**三档阅读层级**:

1. **附件 chip(频道内,一行)**:消息可携带产物附件——`[文档图标] PRD-登录页重设计 · v2 · 2,005 字` + 动作(展开 / 全幅阅读 / 下载)。产物卡、评审卡、Agent 交付事件卡统一用这个 chip 语法;`say` 消息也可引用产物(链接卡:外部 URL 自动成一行链接 chip,站内产物成附件 chip)。
2. **内嵌展开(现状保留)**:chip 点「展开」→ 频道内 markdown 就地渲染(现已实现,视觉规格请顺手统一)。
3. **全幅阅读态(本命题核心 ★)**:chip 或评审卡点「全幅阅读」→ **左侧画布区整体切换为「产物阅读器」**:
   - 阅读器占据画布区全幅;**频道栏保持在右侧**——评审场景下 Boss 左读全文、右侧评审卡就地通过/驳回,这是「对照评审」的关键姿势;
   - 顶部条:面包屑(项目 · 任务 · 产物 vN)+ 版本切换 + 「下载」+ 「回到图」;ESC 也回图;
   - markdown 排版沿 Iris 答复排版(标题层级/表格/代码块),阅读宽度上限约 720-820px 居中;
   - mono 页脚:版本 · 字数 · 产出者 · 时刻(审计血统);
   - 深浅双主题。
   - 「下载」= 另存 .md/.html 到本地(工程负责实现,你定按钮位)。

**交付**:附件 chip 规格(含链接卡变体)/ 阅读器整版(浅+深)/ 评审对照态一版(左阅读器+右评审卡)。

### R2 运行时存在感:执行中 ≠ 安静(P0 ★)

Boss 的原话是「没有那种动效的圈」。现状真相分两半:执行中节点其实有底部扫描条+iris 描边,但它绑在 3s 轮询的 `running` 状态上——**跑得快的任务在两拍之间就完成了,前端从未见过 running**,于是画面全程安静。工程侧将把「在飞信号」(run 状态 + 起跑时刻)直通快照,短跑也可见、elapsed 有真值;你负责让「正在跑」被看见且好看——请设计**状态层执行动效**(红线 5 修订后合法):

- **图上**:`执行中` 节点的常驻轻动效——方向建议:节点边缘进度环 / 描边流光(iris→lavender 慢流)/ 状态点脉动,任选或自创,但强度 < 焦点呼吸,多个可同屏;
- **频道里**:「正在执行」活动行——`Agent·Scribe 正在执行『PRD 起草』 · 已运行 00:24`(elapsed 真值,由后端 run 起始时刻计算),完成后该行消隐、由产物卡接棒;
- **健康条**:「活跃 Agent 1」在有 running 时点亮(iris),与图/频道三处同源同拍;
- reduced-motion:全部降级为静态「执行中」徽记。

### R3 过程的可读:三级下钻 + 即点即关(P0)

任务抽屉的执行 Trace 现状是平铺帧原文(markdown 源码直出),Boss 读不动也关不掉。请对齐产品统一件 **StageStepTrace 三级下钻**(Iris 轮既定:回合折叠 → 步骤 → 原文):

- **一级**:执行摘要一行(模型 · 帧数 · 耗时 · 结果),默认折叠;
- **二级**:步骤列表(每帧一行:类型 + 首行摘要);
- **三级**:点开某帧才见原文;原文若是 markdown **渲染后展示**(或等宽降噪排版),长文内滚;
- **即点即关**:展开控件与收起控件同位吸顶(现在的「过程 N 个瞬间」开关会被长内容推走、trace 区自身不可折叠),任何滚动深度都能一键收起;
- **产出先行**:抽屉信息序改为「产物(最新版,默认展开)→ 验收标准 → 执行过程(折叠)→ 元信息」——Boss 第一眼看到的是结果,不是过程。

### R4 频道即指挥部:@拾取器 + Anna 监察(P0 ★★,本轮灵魂)

两段:

**R4a @拾取器**:composer 输入 `@` 弹出成员浮层——头像 + 姓名 + 职能 + 人/Agent 徽记(`--delegate`),支持继续输入过滤、↑↓ 选择、Enter 确认;选中后文本内 @名 高亮成 mention token。中文 IME 组词过程不得误触发/误发送。空 @(无匹配)不弹硬错误。

**R4b Anna 监察(隐式派活 → 确认卡)**:现在派任务只有显式「+任务」入口;Boss 期望的是**Anna 盯着频道**:当自由发言命中派活意图(如 `@Andy 新任务:全功能回归测试`——@某成员 + 任务性祈使句),Anna 立刻跟一张**任务确认卡**:

```
┌ Anna(起草)────────────────────────────┐
│ 从 Boss 的发言里听出一项新任务:          │
│ 『全功能回归测试』                        │
│ 负责人:Andy(发言中 @ 指定)             │
│ 依赖:实施(Anna 建议,可改)             │
│ 验收:覆盖九屏主流程(草稿,可改)        │
│ [采纳上图]  [调整]  [忽略]               │
└──────────────────────────────────────────┘
```

- 确认卡 = **草稿态**:未采纳不进图、不进审计(零捏造);采纳后节点入场走生长动画,事件卡带「由频道生长 · #aN」溯源;
- 这是图生长的**第四来源**(前三:驳回返工 / +任务 / 阻塞上报);与「+任务」共享同一张起草卡语法,只是触发方式从按钮变成 Anna 听懂了;
- 被派者是 Agent 时,采纳即自动开跑(auto-pilot 既有行为),确认卡上要预告这一点(「采纳后 Agent·Check 将立即执行」);
- 误听(不是派活)时 Boss 点忽略,卡片安静消隐——Anna 的口吻要**轻**:「听出一项新任务」而非「已为你创建」。

**交付**:拾取器浮层规格 / mention token 样式 / 确认卡(含 Agent 预告变体、忽略消隐节奏)/ Anna 监察的口吻文案 3-5 条。

### R5 画布视觉强化:隔三米看得清(P0 ★)

Boss 的评语是「平淡、不突出」。现状节点 = 白卡 + 细边 + 4px 职能点 + 状态小字:状态要凑近读字才知道。目标一句话:**投影到会议室大屏,三米外能看出哪里在跑、哪里卡住、哪里等人。**方向(交你发挥,约束在后):

- **状态即形色**:七态从「文字标注」升级为「形色语汇」——如左缘色条 / 底色轻染 / 状态徽记加大;`执行中` = iris 活性(叠 R2 动效);`阻塞/返工` = danger 系必须刺眼;`完成` = 落章沉稳;`待就绪` 允许更淡(退后);
- **门的仪式感**:评审门是流程的关卡,形态应比普通任务更"重"(金线用在这里;通过后落章);
- **边的层级**:供电实线 / 休眠虚线 / 返工回路 / 焦点流动四型对比拉大,边宽与色可随状态加权;
- **画布空间感**:底纹/网格点阵、并行泳道的轻背景带、或分层色带——让 40% 空白区不显得空;
- **信息密度**:常规 5-15 节点,上限 50 节点仍可读;
- 约束:Iris 暖底不换、iris 唯一主色、金线至多两处、`--delegate` 紫属 Agent、无 emoji、双主题、不做彩虹满屏。

**交付**:七态 + 门三态**全家福**(浅深各一)/ 一版 9 节点并行示例整图(可直接对照现状截图 A 改)。

### R6 全局输入惯例:Enter 发送(P0,轻)

全产品惯例从 `Ctrl+Enter 发送` 改为 **`Enter 发送 / Shift+Enter 换行`**(Boss 习惯,一次改全:Home Chat / Cowork 问 Anna / Create / Crew 频道)。工程负责键位与 IME 守卫(组词中 Enter 不发送);你只需:

- composer 右下微提示的文案与样式(如 `Enter 发送 · Shift+Enter 换行`,ink-3 级,聚焦时才现身?由你定);
- 《设计说明》组件惯例条目同步修订。
