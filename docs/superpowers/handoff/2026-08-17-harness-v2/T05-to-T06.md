## 1. T05 outcome

T05 adds a pure canonical-event Trace projection and versioned Contract/Quality
Eval package. Trace is a read projection only; it does not become a fact source
and it does not move Memory writes across the T04 Owner/grant boundary.

Delivered behavior:

- Trace projection is deterministic by parsed timestamp, stream, sequence and
  event ID, and rejects events outside the requested Workspace/Channel scope;
- Run, independent `tool:<run>:<call>` and `effect:<key>` streams are projected
  into active, completed or explicit orphaned spans;
- live Trace cursors discover scoped Run-related streams and retain one cursor
  per stream, without replaying consumed events;
- unknown/governance events remain visible as scalar span events;
- provider usage and cost are attached only when present; missing usage is not
  replaced with zero values;
- Contract Eval validates canonical scope, artifacts, terminal events,
  prohibited effects and orphaned Trace spans;
- Quality Eval includes prompt/model/rubric versions and canonical evidence in
  its cache identity;
- Smoke Set has 4 distinct scenarios, Dev Set has 16 cases with one deliberate
  prohibited-effect failure, and failed evidence materializes a Regression Case.
