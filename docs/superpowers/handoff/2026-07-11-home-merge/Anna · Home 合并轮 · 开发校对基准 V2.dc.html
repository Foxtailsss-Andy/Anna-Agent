§1 本轮红线

上一档 R1–R10 全部继续生效;以下 N1–N6 为本轮结构性新增 —— 任一条不符,整屏打回
N1视觉语言零改动,结构九决议照单执行
暖瓷白底 / 鸢尾主色 / 金线三处 / 点缀白名单 / 字体三分工 / 动效四则 / 七态纪律 / 拟人可关 / 深色非反相 —— 一寸不动。被推翻的只有三处结构:画布常驻右栏、Create 双栏工作台、三模式侧栏。
常见偏差:借结构改版之机"顺手"换色 / 换圆角 / 加图标库;把旧三段侧栏样式残留在任何屏。
N2模式 pill 只在问候页,运行屏永无切换器
侧栏两段 = Home | Cowork;Chat | Create 是页面级 pill(问候语下方、composer 上方)。会话绑定出生管线,run 内不出现任何模式切换控件 —— 控件不许撒谎(ADR-002)。
常见偏差:把 pill 做进 composer 工具栏(Claude Desktop 样式,决议 02 明确否决);运行屏头部残留模式标签可点。
N3整洁预算:composer 默认可见交互件 ≤ 7(含环境行)
实测:H-01 Chat = 4 件(+ / Anna 档案 / 发送 / 工作空间);H-02 Create = 5 件(另加权限)。场景层与模式层不属于 composer;一切二级内容(模板 / 技能 / 档案 / 工作空间 / 权限 / 连接器)收进弹层面板。
常见偏差:把弹层内容摊回工具栏;给 composer 加第 8 件"顺手的小按钮"。
N4零站位 composer,词表每件有真值
本轮词表全部对应真参数 / 真后端(skill_id · kind · model_profiles · MCP 状态 · 工作空间 · 审批门)。旧虚线站位(附件 / 权限·W4 / CTX·W5 / 开发者工具)已全部迁移或删除,见 §5 迁移表。麦克风 / Web search / ✨增强 / Plan 开关 / usage 一律不画,也不画成「即将上线」。
常见偏差:为"显得完整"补一枚灰态语音钮;连接器面板画成可拨动的假开关(只读状态一览才是真的)。
N5运行屏严格单列;右侧滑出永不自动、永不三块
PlanRail 右柱取消 —— 计划进度与 tokens 观测内嵌 LoopCard 底部观测区;上下文以无字圆环 + 百分比常驻会话 composer 环境行右端(问候页不出现);模型名不入任何观测行。右侧面板默认不存在;入口只有页头产物 chip 与流内锚点 chip;产物流入 = 计数跳动 + 小圆点,绝不自动弹开;面板打开时全屏恰两列。
常见偏差:产物生成完自动弹画布(旧行为);LoopCard 外再画一条计划进度;环带「CTX」字标,或把环画进工具栏 / LoopCard(环只住环境行)。
N6权限两档只属于 Create;Bypass = 琥珀警示
Ask(默认)= 超范围动作弹窗请求确认;Bypass = 完全自主执行,环境行 chip 与弹层选中态一律 warn 色系(#B98A2F / #F8F1E2 / #8F6B24),学 Claude Code 的警示语义。Chat 任何位置不得出现权限件 —— Chat 不写文件系统,挂权限件是假管控。
常见偏差:Chat composer 残留「权限·默认」chip;Bypass 用 danger 红(语义应为 warn 琥珀,红只留给错误)。
N7两模式运行体验同一套组件
Create 流式化后与 Chat 同构:同一 LoopCard、同一办妥语法、同一产物锚点 chip。Create 专属的只有:kind tag、权限 chip、校验/注册收尾段(run 尾内联)、右侧「文件」面板。禁止为 Create 另做一套运行组件。
常见偏差:Create 复用旧双栏工作台;校验/注册画成独立页而非 run 尾收尾段。
