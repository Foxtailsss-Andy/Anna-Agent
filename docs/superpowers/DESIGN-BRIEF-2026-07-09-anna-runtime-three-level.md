# 设计 Brief — Anna Runtime「三级下钻」运行时展示(鸢尾 Iris)

- **日期**:2026-07-09
- **交付对象**:Claude Design(出原型)
- **产出后流程**:原型返稿 → 我们回来按数据契约(§5)落后端 + 重搭前端
- **一句话**:把 Anna 的 Agent 运行过程,设计成 Claude Desktop 那种「三级下钻」的展开 —— **折叠一行 → 展开这一回合做了什么 → 再掀到底看真命令原文和真 stdout** —— 并披上鸢尾 Iris「Anna 大小姐」人格皮。

> **重要前提:不用考虑现有前端。** 现前端(`StageStepTrace` / `LoopCard` / `agentTraceModel`)将被整体撕裂重写,**不作任何保留约束**。你在一张白纸上设计新样式;底下的引擎事件流(§5)是唯一固定的数据地基。

---

## 1. 为什么要这个(设计意图)

这三级展开,就是 Claude Desktop 处理任务时的展开方式,也是「人和 Harness(Agent 运行时)一起思考」的过程可视化。用户高度认同这套模型,要求 Anna 复刻同样的效果:

- **诚实**:每一步做了什么、成没成、真实的命令与输出,都能被掀开查验(「凭证」)。
- **克制**:不看时收拢成一行,不淹没对话。
- **有温度**:在 Iris 设计语言里,这个思考过程要被装饰成有人格的、会呼吸会思考的过程(Anna 大小姐)。

魅力和可信要同时成立:**上面是大小姐的姿态,掀开是工程的收据。**

---

## 2. 参考实例(Claude Desktop 的三级,照着复刻这个手感)

一次真实运行,用户亲手标了三级:

**第一级「我最终看到的」**(折叠行 + 回合间叙述):
```
Ran 2 commands, used a tool
超时了,多半是正则回溯。改用更稳的切割方式重跑。
```

**第二级「一个 Loop 干了什么」**(展开这一回合的带标签步骤):
```
Used PowerShell
Checked Python availability
Failed to extract text and embedded images from WorkBuddy HTML
```

**第三级「真命令原文 + 真 stdout」**(掀开某一步到底):
```
command: $f = Get-Item "…\workbuddy_article_standalone.html"; "{0:N0} bytes" -f $f.Length
description: Check HTML file size
2,906,241 bytes
──
python - <<'EOF'  … (真实脚本原文)  … EOF
Exit code 143
Command timed out after 2m 0s
```

Anna 要的就是**同款三级手感**,但换上鸢尾 Iris 的皮、并遵守下面的规则。

## 3. 要设计什么(三级信息架构)

**分组单元 = 一个「回合」(loop 一轮 = 一次模型思考 + 它触发的那批工具)。** 一次完整运行 = 若干回合竖排 + 回合之间的叙述。每个回合是一个可**独立折叠**的单元(务必保留「下钻到回合级」的能力,不要把所有步骤拍平成一条无分组的长清单)。

| 级 | 是什么 | 内容元素 | 默认态 |
|---|---|---|---|
| **L1 折叠行** | 一个回合收拢成一行(=「我最终看到的」) | ① 拟人状态标签 ② 聚合摘要(如「调用 2 次工具 · 思考」)③ 时态图标(转圈 / ✓ / ✕ / ⏳)④ 耗时 | done→折叠;running / failed / awaiting→展开 |
| **L2 展开回合** | 掀开 L1 → 该回合的有序 Step 列(=「一个 Loop 干了什么」) | 每步一行:类型点(思考 / 工具 / 系统 / 错误)· 动作标签 · 工具成败(✓/✕)· 耗时 | 跟随 L1 |
| **L3 掀单步** | 掀开一个 Step → 真原始(=「真命令 + 真 stdout」) | **工具步**:真请求 args + 真 result / stdout(截断可展开)+ exit / status;**思考步**:完整推理原文 | 收起 |

**硬规则(用户明确要求):**
> **一个 Step 当且仅当它有「超出那行标签之外的留存原文」时,才出现掀开箭头。**
> - 工具步 → 有 L3(args + result)→ **可掀**
> - 思考步 → L3 = 完整推理原文,有则可掀、无则不可掀
> - 系统 / note 步(启动、装载记忆…)→ 无 L3 → **不出箭头、不可掀**
> 即:**运行时没有第三级,就不需要展开。**

**Step 类型(视觉需可区分):** 思考(thinking)· 工具(tool)· 系统(system:启动/装载/记忆)· 错误(error)。

---

## 4. 四种运行状态(每态的形态)

| 状态 | L1 | 细节 |
|---|---|---|
| **running** | 展开 | 顶部「当下行」呼吸 + 拟人文案;当前步转圈 |
| **done** | 折叠成一行 | 拟人「礼成 / 办好啦」+「▸ 回看」可重开全部回合 |
| **failed** | 展开且转红 | **失败步默认掀到 L3 留证**;动效全停 |
| **awaiting** | 展开 | 停在审批 / 等待步;⏳;等外部输入 |

- 用户手动掀开 / 折叠后,**尊重用户选择**,不再被自动态覆写。
- 需要 `prefers-reduced-motion` 降级形态(承 Iris 既有的落笔 / 呼吸降级)。

---

## 5. 拟人层边界(Iris「Anna 大小姐」人格皮)—— 铁律

装饰可以有,但**皮不能骗人**。三条红线,请在设计里显式体现:

1. **皮不盖成败真值。** 失败了就是 ✕,不许还甜甜地说「办好啦~」。成 / 败 / 等待图标是素的、真的。
2. **L3 原始必须素颜。** 真命令、真 stdout 是「凭证」,persona 一个字都不许改写它。
3. **拟人旁白若为现生成文案**,须是**独立、可关**的「flavor」通道,并明确视觉上区别于权威状态字(不能让用户把风格叙述误读成系统事实)。

**可装饰的地方**:L1 / L2 的标签措辞、当下行文案,以及点 / 轨 / 呼吸 / 落笔等动效。用户会在此加动效、思考效果与拟人化描述来贴合 Anna 大小姐人格 —— 请为这些留出充分的表现空间(当下行、时间线轨、瞬间点、状态转场)。

## 6. 数据可用性(工程前提 —— 设计请勿画在不存在的数据上)

这些是原型返稿后我们要落的后端契约。列在这里,是让你知道**每一级实际拿得到什么数据**:

- **引擎已有(地基,不变)**:每回合会产出 `thinking`(流式推理文本)、`tool_start / tool_done`(工具名 + 成败)、以及权威的「我在干嘛」标签(analyze / tool / deliver)。→ **L1、L2 现在就能画。**
- **L3 需后端新增「下钻预览通道」**(我们会做):工具步除成败外,另带 `{args_preview, result_preview, exit/error, bytes, truncated}`。
  - **脱敏**:密钥 / token(如 `ANNA_*_MCP_*`)/ 金额 / PII 在后端产出侧就打码 —— 你拿到的已是脱敏版。
  - **截断 + 懒加载**:大结果(可能几 MB)截断为预览、标 `truncated`,全文按需点开拉取。**请为「预览 + 展开更多 / 加载中」的形态出设计。**
  - **视角门**:全原文默认只对 run owner / 开发者视角可见,他人看脱敏摘要。**请出「可见 vs 受限」两种 L3 形态。**
- **思考步 L3** = 完整推理原文(全文,可长)。**请为长文本的展开 / 折叠形态出设计。**
- **嵌套(暂不做,但留位)**:未来一个 Step 可能本身是一个子运行(subagent 有自己的三级)。**结构上请给「一个步骤里可以再套一层三级」留出视觉延展性**,现在不用画完整交互。

## 7. 交付物(希望 Claude Design 产出)

1. **三级下钻的完整视觉稿**:L1 / L2 / L3 各自形态,以及展开 / 折叠的转场。
2. **四态(running / done / failed / awaiting)** 各自的样子。
3. **Step 四类型**(思考 / 工具 / 系统 / 错误)的视觉区分。
4. **L3 的三种数据形态**:正常预览、`truncated` + 加载更多、受限(脱敏)视角。
5. **拟人层**:当下行 + 动效 + persona 文案示例,并标注哪些元素是「可装饰皮」、哪些是「不可动的权威真值」。
6. **无 L3 步**(无掀开箭头)与**有 L3 步**的对比,坐实「没第三级就不展开」。
7. reduced-motion 降级形态。

沿用鸢尾 Iris 已确立的色彩 / 字体 / 动效语言(落笔、呼吸、发丝轨等),把它延伸到这套三级结构上。

## 附:一次运行喂进 Anna 三级后的样子(供对齐语义)

```
L1(折叠)  第 1 回合 · 调用 2 次工具 · ✓ · 1.2s          ← done 收拢一行
            └ 掀开 ▾
L2(展开)     · 思考   推理与规划                          ← 有推理原文,可掀
              · 工具   Check HTML file size        ✓ 0.1s ← 有 args/result,可掀
              · 工具   Extract images              ✕ 2.0s ← 失败,默认掀到 L3
                └ 掀开 ▾
L3(原始)         args:   { path: "…workbuddy…html" }
                  stdout: (真实输出 / 报错原文,截断可展开)
                  exit:   143 · timed out 2m0s
```

上面每个 ✓/✕/耗时都是真值;persona 皮只作用在标签措辞与动效,掀到 L3 是素颜凭证。
