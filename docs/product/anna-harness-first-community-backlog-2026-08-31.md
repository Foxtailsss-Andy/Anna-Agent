# Harness-first Community Backlog

日期：2026-08-31

此列表明确推迟首发范围，避免把尚未验证的能力描述为可用。
贡献应包含一个可复现失败、最小修改和对应验收；优先使用真实 Host/SDK/SQLite 的公共边界。

| 主题 | 后续验收 | 首发边界 |
| --- | --- | --- |
| 交互控制 | scoped steer/answer/abort，接受与消费可区分，错误关联零执行 | 首发只开放已验证的停止；其他控制不冒充可用 |
| 恢复矩阵 | 部分 ACK、重复重开、最后一帧竞态、失联 Worker 的可复现用例 | 保留基本单 Run/单终态、停止与已完成历史 |
| Coding 能力 | 受权限约束的编辑、命令、测试和 patch 产物 | 未准入前不开放写入/命令执行 |
| Hiker 与 MCP | 真实读取、Owner 批准的写入、回读、unknown 不重放 | 不将通用回答标记为业务办理完成 |
| 多平台 | Windows/Linux 的安装、启动、停止、隔离和打包证据 | 仅声明实际验证的平台 |
| SWE-bench | 固定 Linux x86_64 官方 evaluator、真实实例与可核对报告 | 不宣称 Benchmark Ready 或性能成绩 |
| Memory 与资源 | 提议/接受/编辑/删除/授权 UI，明确来源和跨频道边界 | 复用现有受控读取，不静默学习或扩权 |
| 业务与旧数据 | Create/Crew/Hub、旧记录导入和明确的数据迁移方案 | 旧数据保留，未迁移业务入口关闭 |

任何发现会破坏 Preview 默认执行权、权限、停止、密钥安全或数据完整性的缺陷，立即升级为发布阻断项。
