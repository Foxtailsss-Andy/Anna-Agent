# Harness-first Community Backlog

日期：2026-08-31

对应目标：[HF-PARITY-1.0](anna-harness-product-parity-goal-2026-08-31.md)。原 HF-PREVIEW 范围已作废。

此列表只推迟超出既定产品功能的深化工作。Home、Cowork、Crew 的原功能、基本执行控制及 Hiker 实际读写验收仍属于当前 Goal，不能移入社区 Backlog 以代替完成。
贡献应包含一个可复现失败、最小修改和对应验收；优先使用真实 Host/SDK/SQLite 的公共边界。

| 主题 | 后续验收 | 首发边界 |
| --- | --- | --- |
| 交互控制深化 | 并发交互、重复 ACK、跨进程丢失等组合场景 | 原 Home 的停止、插话和继续必须保留并真实生效 |
| 恢复矩阵 | 部分 ACK、重复重开、最后一帧竞态、失联 Worker 的可复现用例 | 保留基本单 Run/单终态、停止与已完成历史 |
| Coding 能力扩展 | 更多受权限约束的编辑、命令、测试和 patch 能力 | 原 Create 三种产物保留；不开放无治理的任意执行 |
| Hiker 与 MCP 扩展 | 更多业务工具与跨系统事务 | 当前 Goal 仍需真实读取及授权测试写入、回读；只读服务端是外部阻塞 |
| 多平台 | Windows/Linux 的安装、启动、停止、隔离和打包证据 | 仅声明实际验证的平台 |
| SWE-bench | 固定 Linux x86_64 官方 evaluator、真实实例与可核对报告 | 不宣称 Benchmark Ready 或性能成绩 |
| Memory 与资源 | 提议/接受/编辑/删除/授权 UI，明确来源和跨频道边界 | 复用现有受控读取，不静默学习或扩权 |
| 历史 Agent 记录迁移 | 可回退、可核对的旧 Agent Trace 导入 | 保留旧数据和已有业务服务；不将旧 Agent 执行当作 Harness 回退 |

原 S3 未提交实现保留在原集成工作树，可按贡献单独提取；未经复核不进入首发默认路径。
任何破坏原产品功能、Harness 执行权、权限、停止、密钥安全或数据完整性的缺陷，均是发布阻断项。
