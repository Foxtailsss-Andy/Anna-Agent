## 8. 灌数据方式(两条路)

**路 B(推荐,真记账)**:插入主数据 → 插入源单据(发票/账单/收付款/报销)→ 跑 `post()` 生成 GL 凭证
→ 派生 `period_summary`。数字全部"算"出来,最真实。

**路 A(最快,半天)**:插入主数据 + 上面的明细表 + 直接写 `period_summary` 三期值;`get_dashboard_snapshot`
直接读 `period_summary`。够演示,但不是真记账。

无论哪条,**§3/§4 的明细必须与汇总对得上**,否则财务助手深问时会穿帮。
