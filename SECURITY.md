# Security policy

Anna is a local Developer Preview and has no production security support commitment. Do not use it with real enterprise data or credentials until the relevant connector, sandbox, audit, and release controls have been independently reviewed.

Please report suspected vulnerabilities privately through a GitHub Security Advisory after private vulnerability reporting is enabled for the repository. Do not open a public issue containing exploit steps, credentials, customer data, or provider responses.

The preview intentionally fails closed when model/MCP configuration is absent. A green fixture test does not prove connector isolation, hardened sandboxing, installer signing, or production authorization.
